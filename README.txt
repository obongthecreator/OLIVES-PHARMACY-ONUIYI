Olives Pharmacy - Inventory & Sales System
==========================================

Installation
1. Save the plugin file as `olives-pharmacy.php`.
2. Zip it (or place it in a folder named `olives-pharmacy` and zip the folder).
3. In WordPress, go to Plugins > Add New > Upload Plugin, upload, install, and activate.

After activation, the plugin auto-creates required database tables and six pages (Home, Dashboard, Stock, Sales, Financial, Analytics), and seeds demo products if the products table is empty.
